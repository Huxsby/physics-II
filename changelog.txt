# Changelog del proyecto

## General
- **Refactorización Completa (Junio 2025):** Se ha reestructurado todo el proyecto para seguir las convenciones estándar de Python, mejorar la mantenibilidad y facilitar la ejecución de scripts y pruebas.
- Se ha adoptado el uso de radianes como unidad estándar para todos los cálculos angulares internos.

## Cambios Recientes (22 de Junio de 2025)
- **Corrección de Importaciones:** Se han solucionado errores de `ImportError` y `ModuleNotFoundError` en varios módulos dentro de `src/calculations` y `tests`.
  - **Causa:** Los scripts se ejecutaban directamente, pero las importaciones (ej. `from src.core...`) requerían que el proyecto se ejecutara como un paquete.
  - **Solución:** Se ha añadido código a cada script para modificar dinámicamente `sys.path`, añadiendo el directorio raíz del proyecto. Esto permite que los scripts sean ejecutables de forma individual para facilitar las pruebas y el desarrollo, manteniendo al mismo tiempo la estructura de importación absoluta.

## Nueva Estructura del proyecto
El proyecto ahora sigue una organización modular y escalable:

- **/src/**: Contiene todo el código fuente principal de la librería de robótica.
  - **/src/core/**: Clases base como `Robot`, `Link`, y funciones para cargar configuraciones.
  - **/src/calculations/**: Módulos para cálculos de cinemática, jacobiana, rotaciones, etc.
  - **/src/simulation/**: Código para visualización, ploteo y animación de robots.
- **/scripts/**: Scripts ejecutables para realizar análisis, predicciones o tareas específicas.
- **/tests/**: Pruebas unitarias y de integración. Contiene el menú principal de pruebas (`main.py`).
- **/config/**: Archivos de configuración, como los ficheros `.yaml` que definen los robots.
- **/data/**: Datos de entrada o datasets (ej. `data_θi.txt`, `tiempos_workspace.csv`).
- **/results/**: Para guardar los resultados generados, como imágenes, GIFs o logs.
- **/docs/**: Documentación del proyecto.

## Sistema de Paquetes y Ejecución
- **Paquete Instalable:** El código en `src` ahora es un paquete de Python instalable. Se ha añadido un archivo `pyproject.toml`.
- **Instalación Editable:** Para el desarrollo, el paquete se instala con `pip install -e .` desde la raíz del proyecto. Esto permite que los cambios en `src` se reflejen inmediatamente sin necesidad de reinstalar.
- **Importaciones Absolutas:** Todas las importaciones ahora son absolutas desde la raíz del paquete `src` (ej. `from src.core import Robot`), lo que elimina errores de importación relativa.
- **Ejecución de Pruebas:** La forma recomendada de ejecutar el menú de pruebas es desde la raíz del proyecto: `python -m tests.main`.
