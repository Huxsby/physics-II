FABRIK-R: Una extensión de FABRIK para manipuladores robóticos
FABRIK-R (FABRIK for Robotics) es una adaptación del algoritmo FABRIK diseñada para abordar las cinemáticas inversas de manipuladores en serie, teniendo en cuenta las restricciones de rotación de las articulaciones.

Definiciones Clave
Puntos de Articulación (Joint Points): p_i para i = 0, ..., n, donde p_0 es la base y p_n es el efector final.
Vector de Eslabón (Link Vector): v_i = p_{i+1} - p_i.
Longitud de Eslabón (Link Length): d_i = ||v_i||.
Objetivo (Target): t.
Tolerancia (Tolerance): tol. Un valor pequeño para determinar cuándo el efector final está lo suficientemente cerca del objetivo.
Ejes de Articulación (Joint Axes): u_i es el vector unitario que representa el eje de rotación para la articulación i.
Restricciones Angulares (Angular Constraints): Cada articulación i puede tener límites de rotación (mínimo y máximo).
Pseudocódigo del Algoritmo FABRIK-R
El algoritmo funciona de manera iterativa en dos fases principales: un paso hacia adelante (forward pass) y un paso hacia atrás (backward pass).

FUNCIÓN FABRIK_R(p, t, d, u, tol, max_iter):
    // p: lista de puntos de articulación [p_0, ..., p_n]
    // t: punto objetivo
    // d: lista de longitudes de eslabón [d_0, ..., d_{n-1}]
    // u: lista de ejes de rotación de las articulaciones [u_0, ..., u_{n-1}]
    // tol: tolerancia de error
    // max_iter: número máximo de iteraciones

    iter = 0
    dist = ||p_n - t||

    MIENTRAS (dist > tol Y iter < max_iter):
        // --- FASE 1: HACIA ATRÁS (Backward Pass) ---
        // Mover el efector final al objetivo
        p_n = t

        PARA i DESDE n-1 HASTA 0:
            // Vector desde la nueva posición de la articulación i+1 a la articulación i
            v_backward = p_i - p_{i+1}
            
            // Vector unitario en la dirección del eslabón
            lambda_backward = v_backward / ||v_backward||
            
            // Calcular la nueva posición para la articulación i
            p_i = p_{i+1} + lambda_backward * d_i

        // --- FASE 2: HACIA ADELANTE (Forward Pass) ---
        // Reajustar la base a su posición original
        p_0 = base_original 

        PARA i DESDE 0 HASTA n-1:
            // Vector desde la nueva posición de la articulación i a la articulación i+1
            v_forward = p_{i+1} - p_i
            
            // Vector unitario en la dirección del eslabón
            lambda_forward = v_forward / ||v_forward||
            
            // Calcular la nueva posición para la articulación i+1
            p_{i+1} = p_i + lambda_forward * d_i

        // --- FASE 3: APLICAR RESTRICCIONES DE ARTICULACIÓN ---
        PARA i DESDE 1 HASTA n-1:
            // Vector del eslabón anterior (i-1) y del eslabón actual (i)
            v_prev = p_i - p_{i-1}
            v_curr = p_{i+1} - p_i

            // Calcular el ángulo entre los eslabones y aplicar restricciones
            // (Esta parte requiere proyecciones sobre el plano de rotación
            // definido por el eje u_i y la aplicación de los límites angulares)
            
            // 1. Proyectar los vectores sobre el plano normal al eje de la articulación u_{i-1}
            v_prev_proj = v_prev - (v_prev · u_{i-1}) * u_{i-1}
            v_curr_proj = v_curr - (v_curr · u_{i-1}) * u_{i-1}

            // 2. Calcular el ángulo y restringirlo si es necesario
            angle = acos( (v_prev_proj · v_curr_proj) / (||v_prev_proj|| * ||v_curr_proj||) )
            constrained_angle = clamp(angle, min_angle_i, max_angle_i)

            // 3. Si el ángulo fue restringido, rotar el eslabón actual para que coincida
            si (angle != constrained_angle):
                // Calcular el eje de rotación para el ajuste
                rotation_axis = cross(v_prev_proj, v_curr_proj)
                // Aplicar la rotación al vector v_curr para obtener v_curr_new
                v_curr_new = rotate(v_curr, rotation_axis, constrained_angle - angle)
                // Actualizar la posición de la siguiente articulación
                p_{i+1} = p_i + v_curr_new

        // Actualizar distancia y contador
        dist = ||p_n - t||
        iter = iter + 1

    DEVOLVER p


Explicación Detallada
Inicialización:

El algoritmo comienza con la cadena de articulaciones p en una configuración inicial.
Se calcula la distancia entre el efector final p_n y el objetivo t.
El bucle principal se ejecuta mientras esta distancia sea mayor que la tolerancia y no se exceda el número máximo de iteraciones.
Fase 1: Hacia Atrás (Reaching)

El propósito de esta fase es mover la cadena cinemática hacia el objetivo.
Se coloca el efector final p_n directamente sobre el punto objetivo t.
Luego, se recorren las articulaciones hacia atrás, desde n-1 hasta la base (0).
Para cada articulación p_i, se calcula su nueva posición manteniéndola en la línea que une la nueva posición de p_{i+1} y la antigua p_i, pero a la distancia correcta d_i.
Fase 2: Hacia Adelante (Returning)

Después del paso hacia atrás, la base p_0 se habrá movido de su posición original.
Esta fase restaura la cadena a su punto de origen.
Se fija p_0 en su posición inicial.
Se recorren las articulaciones hacia adelante, desde 0 hasta n-1.
De manera similar a la fase anterior, cada p_{i+1} se reposiciona a lo largo de la línea que une la nueva p_i y la antigua p_{i+1}, conservando la longitud del eslabón d_i.
Fase 3: Aplicación de Restricciones (Constraint Application)

Esta es la contribución principal de FABRIK-R. Después de cada par de fases (hacia atrás y hacia adelante), las articulaciones pueden haber adoptado ángulos que no son físicamente posibles para el robot.
Se itera a través de las articulaciones intermedias (desde 1 hasta n-1).
Para cada articulación i, se calcula el ángulo formado por los eslabones v_{i-1} y v_i.
Este cálculo se realiza en el plano de rotación de la articulación, que es normal a su eje de rotación u_{i-1}.
Si el ángulo calculado está fuera de los límites permitidos para esa articulación, se ajusta al límite más cercano (mínimo o máximo).
Para reflejar este ajuste, el eslabón v_i (y por lo tanto, la posición de p_{i+1}) se rota para que coincida con el ángulo restringido. Esto afecta a todas las articulaciones posteriores en la cadena.
Convergencia:

El proceso se repite hasta que la distancia entre el efector final y el objetivo sea menor que la tolerancia tol, o hasta que se alcance el número máximo de iteraciones.
Este procedimiento permite que FABRIK-R encuentre una solución de cinemática inversa que no solo alcanza el objetivo, sino que también respeta las limitaciones mecánicas del manipulador robótico.
