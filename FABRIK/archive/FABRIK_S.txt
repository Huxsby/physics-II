INSTRUCCIONES ORIGINALES DEL PAPER:
"An adaptation of FABRIK algorithm for serial robot's inverse kinematics"

ALGORITHM 1: Forward and Backward Reaching Inverse Kinematics (FABRIK)
Input: Initial joint positions p₀, p₁, ..., pₙ and target position t
Output: Final joint positions that reach target t

1. Check if target is reachable (distance from base to target ≤ total chain length)
2. If target is unreachable, stretch toward target
3. If target is reachable:
   - FORWARD REACH: Set end-effector to target position
   - For i = n-1 down to 0: Update joint positions maintaining link constraints
   - BACKWARD REACH: Set base to original position  
   - For i = 1 to n: Update joint positions maintaining link constraints
4. Repeat until convergence or max iterations reached

ADAPTACIÓN PARA ROBOTS SERIALES:
- Extensión a 6DOF (posición + orientación)
- Soporte para articulaciones rotacionales (revolute) y prismáticas
- Manejo de restricciones articulares (límites angulares/lineales)
- Representación mediante teoría de tornillos (screw theory)
- Cálculo de errores RMSE para posición y orientación

TIPOS DE ARTICULACIONES SOPORTADAS:
- REVOLUTE/HINGE: Articulación rotacional con eje fijo
- PIVOTE: Articulación rotacional especial para robots seriales  
- PRISMATIC: Articulación lineal/prismática

CONFIGURACIÓN INICIAL:
- Límite de iteraciones: 200
- Tolerancia de error: 1e-3
- Umbral RMSE: 10
- Representación: Teoría de Tornillos (Screw Theory)
- Coordenadas: Vectores cartesianos 3D y matrices de rotación 3x3

FUNCIÓN CalculatePositionError(P_final, P_target):
    RETORNAR P_final - P_target

FUNCIÓN CalculateOrientationError(O_final, O_target):
    M = O_final * Transpose(O_target)
    RETORNAR [M[3,2] - M[2,3], M[1,3] - M[3,1], M[2,1] - M[1,2]]

FUNCIÓN CalculateRMSE(error_pos, error_ori, position_only):
    SI position_only:
        RETORNAR |error_pos| * sqrt(1/3)
    SINO:
        RETORNAR sqrt(|error_pos|² + |error_ori|²) * sqrt(1/6)

FUNCIÓN CrossProduct(v1, v2):
    RETORNAR [v1.y*v2.z - v1.z*v2.y, 
              v1.z*v2.x - v1.x*v2.z, 
              v1.x*v2.y - v1.y*v2.x]

FUNCIÓN DotProduct(v1, v2):
    RETORNAR v1.x*v2.x + v1.y*v2.y + v1.z*v2.z

FUNCIÓN Normalize(vector):
    magnitude = sqrt(vector.x² + vector.y² + vector.z²)
    SI magnitude ≈ 0:
        RETORNAR previous_valid_vector
    RETORNAR vector / magnitude

FUNCIÓN Sign(value):
    SI value ≥ 0: RETORNAR 1
    SINO: RETORNAR -1

FUNCIÓN EstimateTargetOrientation(chain, target_position):
    // Encontrar primera articulación revolute
    first_revolute = -1
    PARA i = 0 HASTA chain.n_joints-1:
        SI chain.joints[i].tipo == REVOLUTE:
            first_revolute = i
            ROMPER

    SI first_revolute == -1:
        RETORNAR identity_orientation

    // Calcular nuevo eje z
    difference = target_position - chain.positions[first_revolute]
    z_new = Normalize(difference)
    
    // Eje z actual
    z_current = chain.orientations[n-1][:, 2]  // columna z
    
    // Calcular rotor y ángulo para Rodrigues
    cross_product = CrossProduct(z_new, z_current)
    cross_magnitude = |cross_product|
    
    SI cross_magnitude ≈ 0:
        RETORNAR chain.orientations[n-1]
    
    k = cross_product / cross_magnitude
    theta = arccos(DotProduct(z_new, z_current))
    
    // Aplicar rotación de Rodrigues simplificada
    target_orientation = ApplyRodriguesRotation(chain.orientations[n-1], k, theta)
    
    RETORNAR target_orientation

FUNCIÓN SolveRevoluteJoint(i, chain, direction):
    // ENTRADA: índice i, cadena cinemática, dirección (FORWARD/BACKWARD)
    // SALIDA: nueva posición y orientación para articulación i
    
    SI direction == FORWARD:
        i_current = i
        i_next = i + 1
    SINO:
        i_current = i
        i_next = i - 1
    
    // Paso 1: Calcular vector distancia
    d_i = chain.positions[i_next] - chain.positions[i_current]
    
    // Paso 2: Obtener eje x (se hereda en revolute joints)
    x_next = chain.orientations[i_next][:, 0]  // columna x
    
    // Paso 3: Proyectar al plano ortogonal a x
    projection = DotProduct(d_i, x_next) * x_next
    difference = d_i - projection
    diff_magnitude = |difference|
    
    SI diff_magnitude ≈ 0:
        z_new = chain.orientations[i_next][:, 2]  // columna z
    SINO:
        z_new = difference / diff_magnitude
    
    // Paso 4: Calcular nueva posición
    length = chain.joints[i_current].longitud
    chain.positions[i_current] = chain.positions[i_next] - z_new * length
    
    // Paso 5: Heredar eje x y calcular y
    x_new = x_next
    y_new = CrossProduct(z_new, x_new)
    
    // Paso 6: Actualizar orientación
    chain.orientations[i_current][:, 0] = x_new
    chain.orientations[i_current][:, 1] = y_new
    chain.orientations[i_current][:, 2] = z_new
    
    // Paso 7: Verificar restricciones angulares
    CheckRevoluteJointLimits(i_current, chain)

FUNCIÓN CheckRevoluteJointLimits(i, chain):
    i_next = i + 1
    SI i_next >= chain.n_joints: RETORNAR
    
    z_current = chain.orientations[i][:, 2]
    z_next = chain.orientations[i_next][:, 2]
    x_current = chain.orientations[i][:, 0]
    
    // Calcular ángulo actual
    dot_product = DotProduct(z_current, z_next)
    cross_product = CrossProduct(z_current, z_next)
    sign = Sign(DotProduct(cross_product, x_current))
    
    current_angle = arccos(CLAMP(dot_product, -1, 1)) * sign
    
    limit_min = chain.joints[i].limite_min
    limit_max = chain.joints[i].limite_max
    
    SI current_angle > limit_max O current_angle < limit_min:
        q_L = (current_angle > limit_max) ? limit_max : limit_min
        
        y_next = chain.orientations[i_next][:, 1]
        z_corrected = z_next * cos(q_L) + y_next * sin(q_L)
        
        chain.orientations[i][:, 2] = z_corrected
        chain.orientations[i][:, 1] = CrossProduct(z_corrected, x_current)

FUNCIÓN SolvePivotJoint(i, chain, direction):
    // ENTRADA: índice i, cadena cinemática, dirección (FORWARD/BACKWARD)
    // SALIDA: nueva posición y orientación para articulación i
    
    SI direction == FORWARD:
        i_current = i
        i_next = i + 1
    SINO:
        i_current = i
        i_next = i - 1
    
    // Paso 1: Heredar eje z (característico de pivote)
    z_new = chain.orientations[i_next][:, 2]
    
    // Paso 2: Calcular nueva posición
    length = chain.joints[i_current].longitud
    chain.positions[i_current] = chain.positions[i_next] - z_new * length
    
    // Paso 3: Encontrar articulación revolute previa (i-2)
    i_prev_revolute = -1
    PARA j = i_current-1 HACIA ABAJO HASTA 0:
        SI chain.joints[j].tipo == REVOLUTE:
            i_prev_revolute = j - 1  // Posición antes de la revolute
            ROMPER
    
    SI i_prev_revolute == -1:
        // Usar orientación anterior si no hay revolute previa
        x_new = chain.orientations[i_next][:, 0]
    SINO:
        // Paso 4: Calcular nuevo eje x basado en revolute previa
        d_i = chain.positions[i_current] - chain.positions[i_prev_revolute]
        z_prev = Normalize(d_i)
        
        cross_product = CrossProduct(z_new, z_prev)
        cross_magnitude = |cross_product|
        
        SI cross_magnitude ≈ 0:
            x_new = chain.orientations[i_next][:, 0]
        SINO:
            x_new = cross_product / cross_magnitude
            
            // Evitar flip inesperado
            x_previous = chain.orientations[i_current][:, 0]
            SI DotProduct(x_new, x_previous) < 0:
                x_new = -x_new
    
    // Paso 5: Calcular eje y
    y_new = CrossProduct(z_new, x_new)
    
    // Paso 6: Actualizar orientación
    chain.orientations[i_current][:, 0] = x_new
    chain.orientations[i_current][:, 1] = y_new
    chain.orientations[i_current][:, 2] = z_new
    
    // Paso 7: Verificar restricciones angulares
    CheckPivotJointLimits(i_current, chain)

FUNCIÓN CheckPivotJointLimits(i, chain):
    i_next = i + 1
    SI i_next >= chain.n_joints: RETORNAR
    
    x_current = chain.orientations[i][:, 0]
    x_next = chain.orientations[i_next][:, 0]
    z_current = chain.orientations[i][:, 2]
    
    // Calcular ángulo actual
    dot_product = DotProduct(x_current, x_next)
    cross_product = CrossProduct(x_current, x_next)
    sign = Sign(DotProduct(cross_product, z_current))
    
    current_angle = arccos(CLAMP(dot_product, -1, 1)) * sign
    
    limit_min = chain.joints[i].limite_min
    limit_max = chain.joints[i].limite_max
    
    SI current_angle > limit_max O current_angle < limit_min:
        q_L = (current_angle > limit_max) ? limit_max : limit_min
        
        y_next = chain.orientations[i_next][:, 1]
        x_corrected = x_next * cos(q_L) - y_next * sin(q_L)
        
        chain.orientations[i][:, 0] = x_corrected
        chain.orientations[i][:, 1] = CrossProduct(z_current, x_corrected)

FUNCIÓN SolvePrismaticJoint(i, chain, direction):
    // ENTRADA: índice i, cadena cinemática, dirección (FORWARD/BACKWARD)
    // SALIDA: nueva longitud y posición para articulación i
    
    SI direction == FORWARD:
        i_current = i
        i_next = i + 1
    SINO:
        i_current = i
        i_next = i - 1
    
    // Paso 1: Calcular vector distancia
    d_i = chain.positions[i_next] - chain.positions[i_current]
    
    // Paso 2: Obtener eje z (dirección prismática)
    z_current = chain.orientations[i_current][:, 2]
    
    // Paso 3: Calcular nueva longitud proyectando en eje z
    new_length = DotProduct(d_i, z_current)
    
    // Paso 4: Aplicar límites
    limit_min = chain.joints[i_current].limite_min
    limit_max = chain.joints[i_current].limite_max
    
    SI new_length > limit_max:
        new_length = limit_max
    SI new_length < limit_min:
        new_length = limit_min
    
    // Paso 5: Actualizar longitud y posición
    chain.joints[i_current].longitud = new_length
    chain.positions[i_current] = chain.positions[i_next] - z_current * new_length

5. ALGORITMO PRINCIPAL FABRIK ADAPTADO

FUNCIÓN FABRIK_SerialRobots(initial_chain, target):
    // ENTRADA: cadena cinemática inicial, objetivo (posición y/o orientación)
    // SALIDA: valores articulares finales, RMSE final, número iteraciones
    
    // Inicialización
    chain = CopyChain(initial_chain)
    iterations = 0
    MAX_ITERATIONS = 200
    TOLERANCE = 1e-3
    
    // Estimar orientación si solo hay posición objetivo
    SI target.position_only:
        target.orientation = EstimateTargetOrientation(chain, target.position)
    
    // Calcular error inicial
    final_position = chain.positions[chain.n_joints - 1]
    final_orientation = chain.orientations[chain.n_joints - 1]
    
    pos_error = CalculatePositionError(final_position, target.position)
    ori_error = CalculateOrientationError(final_orientation, target.orientation)
    total_error = CalculateRMSE(pos_error, ori_error, target.position_only)
    
    // Guardar posición y orientación de base original
    base_position_original = chain.positions[0]
    base_orientation_original = chain.orientations[0]
    
    // BUCLE PRINCIPAL
    MIENTRAS (total_error > TOLERANCE Y iterations < MAX_ITERATIONS):
        
        // ===== ETAPA FORWARD REACH =====
        // Establecer objetivo en el end-effector
        chain.positions[chain.n_joints - 1] = target.position
        chain.orientations[chain.n_joints - 1] = target.orientation
        
        // Resolver hacia atrás desde end-effector hasta base
        PARA i = chain.n_joints - 2 HACIA ABAJO HASTA 0:
            SEGÚN chain.joints[i].tipo:
                CASO REVOLUTE:
                    SolveRevoluteJoint(i, chain, FORWARD)
                CASO PIVOTE:
                    SolvePivotJoint(i, chain, FORWARD)
                CASO PRISMATIC:
                    SolvePrismaticJoint(i, chain, FORWARD)
        
        // Verificar error en base después del forward reach
        base_pos_error = |chain.positions[0] - base_position_original|
        base_ori_error = |CalculateOrientationError(chain.orientations[0], base_orientation_original)|
        base_error = sqrt(base_pos_error² + base_ori_error²)
        
        SI base_error ≤ TOLERANCE:
            ROMPER  // Convergencia después del forward reach
        
        // ===== ETAPA BACKWARD REACH =====
        // Restaurar base original
        chain.positions[0] = base_position_original
        chain.orientations[0] = base_orientation_original
        
        // Resolver hacia adelante desde base hasta end-effector
        PARA i = 1 HASTA chain.n_joints - 1:
            SEGÚN chain.joints[i].tipo:
                CASO REVOLUTE:
                    SolveRevoluteJoint(i, chain, BACKWARD)
                CASO PIVOTE:
                    SolvePivotJoint(i, chain, BACKWARD)
                CASO PRISMATIC:
                    SolvePrismaticJoint(i, chain, BACKWARD)
        
        // Recalcular error total
        final_position = chain.positions[chain.n_joints - 1]
        final_orientation = chain.orientations[chain.n_joints - 1]
        
        pos_error = CalculatePositionError(final_position, target.position)
        ori_error = CalculateOrientationError(final_orientation, target.orientation)
        total_error = CalculateRMSE(pos_error, ori_error, target.position_only)
        
        iterations++
    
    // Extraer valores articulares finales
    joint_values = ExtractJointValues(chain)
    
    RETORNAR joint_values, total_error, iterations

FUNCIÓN ExtractJointValues(chain):
    values = Array[Real](chain.n_joints)
    
    PARA i = 0 HASTA chain.n_joints - 1:
        SEGÚN chain.joints[i].tipo:
            CASO REVOLUTE O PIVOTE:
                // Calcular ángulo basado en orientaciones consecutivas
                SI i < chain.n_joints - 1:
                    values[i] = CalculateJointAngle(i, chain)
                SINO:
                    values[i] = 0  // Última articulación
            
            CASO PRISMATIC:
                values[i] = chain.joints[i].longitud
    
    RETORNAR values

FUNCIÓN CalculateJointAngle(i, chain):
    // Implementación específica según tipo de articulación
    // Similar a las verificaciones de límites pero retornando el ángulo actual
    
    SEGÚN chain.joints[i].tipo:
        CASO REVOLUTE:
            z_current = chain.orientations[i][:, 2]
            z_next = chain.orientations[i+1][:, 2]
            x_current = chain.orientations[i][:, 0]
            
            dot_product = DotProduct(z_current, z_next)
            cross_product = CrossProduct(z_current, z_next)
            sign = Sign(DotProduct(cross_product, x_current))
            
            RETORNAR arccos(CLAMP(dot_product, -1, 1)) * sign
        
        CASO PIVOTE:
            x_current = chain.orientations[i][:, 0]
            x_next = chain.orientations[i+1][:, 0]
            z_current = chain.orientations[i][:, 2]
            
            dot_product = DotProduct(x_current, x_next)
            cross_product = CrossProduct(x_current, x_next)
            sign = Sign(DotProduct(cross_product, z_current))
            
            RETORNAR arccos(CLAMP(dot_product, -1, 1)) * sign

FUNCIÓN CLAMP(valor, minimo, maximo):
    SI valor < minimo: RETORNAR minimo
    SI valor > maximo: RETORNAR maximo
    RETORNAR valor

FUNCIÓN ApplyRodriguesRotation(base_orientation, axis_k, angle_theta):
    // Implementación simplificada de rotación de Rodrigues
    // Para rotar base_orientation alrededor del eje k por ángulo theta
    cos_theta = cos(angle_theta)
    sin_theta = sin(angle_theta)
    
    // Matriz de rotación de Rodrigues
    K = SkewSymmetricMatrix(axis_k)
    R = IdentityMatrix() + sin_theta * K + (1 - cos_theta) * K * K
    
    RETORNAR R * base_orientation

FUNCIÓN SkewSymmetricMatrix(vector):
    // Crear matriz antisimétrica para producto cruzado
    RETORNAR [[0, -vector.z, vector.y],
              [vector.z, 0, -vector.x],
              [-vector.y, vector.x, 0]]

FUNCIÓN CopyChain(original_chain):
    // Crear copia profunda de la cadena cinemática
    chain_copy = NewSerialChain()
    chain_copy.n_joints = original_chain.n_joints
    
    PARA i = 0 HASTA original_chain.n_joints - 1:
        chain_copy.joints[i] = CopyJoint(original_chain.joints[i])
        chain_copy.positions[i] = CopyVector(original_chain.positions[i])
        chain_copy.orientations[i] = CopyMatrix(original_chain.orientations[i])
    
    RETORNAR chain_copy
